ver 5.1.1.2 (not released)
- Licenses: the library uses only the API of the ka_licenses module (api_version 1), the old scripts extension/domain_info and extension/register_key are not called any more (the license server ka-station is updated together with the library). The Ka Extensions page asks for the state of all Ka Extensions modules with one request to index.php?route=extension/ka_extensions/ka_licenses/api/checkModules (vendor ka_extensions, code, edition - install.json 'edition' or oc4, the Opencart version); registered and free modules are saved as before, unregistered and expired ones are not registered. The registration of a key goes to .../ka_licenses/api/linkLicense (license_key, surface_uri, vendor, code, edition, opencart_version). When the license server is not available or its answer is not valid (connection refused, timeout, HTTP 404 / 5xx, empty or not JSON answer, no api_version) or it returns an error, nothing is changed: one request, the saved states are kept, no module is disabled or shown as unlicensed, the error is written to the log. Tests: tests/run.php testLicenseServer (a local test server tests/fixtures/license_server).
