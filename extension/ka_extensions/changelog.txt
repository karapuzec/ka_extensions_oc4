ver 5.1.1.2
- Licenses: the library uses only the API of the ka_licenses module (api_version 1), the old scripts extension/domain_info and extension/register_key are not called any more (the license server ka-station is updated together with the library). The Ka Extensions page asks for the state of all Ka Extensions modules with one request to index.php?route=extension/ka_extensions/ka_licenses/api/checkModules (vendor ka_extensions, code, edition - install.json 'edition' or oc4, the Opencart version); registered and free modules are saved as before, unregistered and expired ones are not registered. The registration of a key goes to .../ka_licenses/api/linkLicense (license_key, surface_uri, vendor, code, edition, opencart_version). When the license server is not available or its answer is not valid (connection refused, timeout, HTTP 404 / 5xx, empty or not JSON answer, no api_version) or it returns an error, nothing is changed: one request, the saved states are kept, no module is disabled or shown as unlicensed, the error is written to the log. Tests: tests/run.php testLicenseServer (a local test server tests/fixtures/license_server).
- HiddenSettings: hidden values of a module (installed version, counters, reference data) in the group '<ext_code>_hidden' of the setting table, ported from Ka Extensions for OpenCart 3 (get, set, increase). Saving the settings page does not overwrite them;
- Curl::request(): new option 'verify_ssl' => true verifies the certificate of the server. It is off by default as before (backward compatibility), modules calling external APIs should turn it on. getFileContentsByUrl() is not changed;
- Curl::request(): webauth_password is sent as it is with the Basic authorization (it was url-encoded, so passwords with special characters did not work); the 'Expect:' header is sent as in the OpenCart 3 library (with older curl versions large POST bodies got an interim 100 response); getLastStatusCode() returns the HTTP status code of the last response, the body of 4xx/5xx responses is returned as before;
- forms: the messages of required and missing fields show the field title ('title' of the field or the language text txt_title_<code>) instead of the field code;
- field templates (@ka_common/fields/*.twig) escape field values, placeholders and option values / select option labels with the new Twig filter ka_escape (quotes and tags are encoded, values saved by OpenCart with htmlspecialchars() are not encoded twice). Titles, tooltips and errors are shown as before (they are language texts and may have HTML);
- ControllerSettings: a module can set protected $keep_settings_on_uninstall = true to keep its settings on uninstallation (they are deleted by default as before).;
- forms: validateField() returns false after the min_value / max_value error, an empty number field that is not required skips the limits;
- documentation: All Documentation, GitHub and Releases links.

- Theme Editor: saving a template is not a fatal error anymore, templates changed in the Theme Editor work with module child templates;
- Store: serialized settings are read correctly; KaURLify LogicException namespace fixed;
- ControllerInstaller: properties are protected;
- typos, docblocks and documentation guides.
