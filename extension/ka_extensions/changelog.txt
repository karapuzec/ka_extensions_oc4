ver 5.1.1.2 (not released)
- Licenses: new requests to the API of the ka_licenses module (api_version 1): the Ka Extensions page asks for the state of all Ka Extensions modules with one request to index.php?route=extension/ka_extensions/ka_licenses/api/checkModules (vendor ka_extensions, code, edition - install.json 'edition' or oc4, the Opencart version); registered and free modules are saved as before, unregistered and expired ones are not registered. The registration of a key goes to .../ka_licenses/api/linkLicense (license_key, surface_uri, vendor, code, edition, opencart_version). A new server is detected by api_version in its JSON answer; without it (an old ka-station: 404 page) or on an error answer of checkModules the old request is sent to the old url (extension/domain_info, extension/register_key) with the old fields, as before. When the license server is not available (connection refused, timeout, HTTP 5xx, empty or not JSON answer) nothing is changed: the saved states are kept, no module is disabled or shown as unlicensed. Tests: tests/run.php testLicenseServer (a local test server tests/fixtures/license_server).
