# Ka Extensions for OpenCart 4

A shared library for OpenCart 4 modules of [Karapuz Team](https://www.ka-station.com/ka-extensions-for-opencart-4):
the kamod engine (changing OpenCart classes and templates by inheritance), kapatch and base classes for modules.

- Code: `extension/ka_extensions/`
- Documentation sources: `docgen/guides/`
- Development, building the package, tests: [DEVELOPMENT.md](DEVELOPMENT.md)
